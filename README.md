# Colophon

A native macOS Markdown editor for developers — beautiful enough that it doesn't look like a developer tool. Open source, focused, and built to be the interface between you and your AI agents.

> **Status: pre-alpha (milestone M0 — project scaffolding).** Not yet usable. Watch/star to follow along.

## What it is

Colophon is a **native** macOS Markdown editor (AppKit + SwiftUI, no Electron) for people who write a lot of Markdown: READMEs, technical docs, `CLAUDE.md` / `AGENTS.md`, specs, blog posts, notes.

- **Native & fast** — instant launch, low memory, no web bloat; deep macOS integration.
- **Simple & beautiful** — considered typography, calibrated layout, a quiet interface. Craft over feature count.
- **Agent-aware** — Markdown is now the protocol between humans and AI agents. Colophon aims to be the best place to author the Markdown you write *for* agents, and to read the Markdown they write *for* you.

## Two promises we will never break

1. **Colophon is, and will remain, free and open source.**
2. **Your local `.md` files are the single source of truth.** No proprietary format, ever. Everything you write stays as plain Markdown in your own folders, and you can walk away at any time with zero export.
